## ✨ Features

### 👤 User Features
- Browse vehicles with search, category & price filters
- Smart booking calendar (Flatpickr) with real-time availability
- Dynamic price calculator on selection
- My Bookings dashboard with status tracking
- View & download PDF invoices
- Automated email notifications for every booking action
- Fully responsive mobile-first design

### 👑 Admin Features
- Dashboard with revenue stats & Chart.js analytics
- Manage bookings (Approve / Reject / Complete)
- Fleet management (Add / Edit / Delete vehicles)
- User management (View / Block / Unblock / Delete)
- Role-based access control & blocked-user middleware
- Tabbed booking filters & pagination

### 🛡️ Other Features
- Custom 404 / 403 / 500 error pages
- Contact form with email integration
- About, FAQ, Terms & Privacy pages
- Secure authentication (Laravel Breeze)
- Optimized pagination for large datasets

## 🛠️ Tech Stack
| Layer | Technology |
|:------|:-----------|
| **Backend** | Laravel 11, PHP 8.2+ |
| **Frontend** | Tailwind CSS, Alpine.js |
| **Database** | MySQL |
| **Calendar** | Flatpickr |
| **Charts** | Chart.js |
| **PDF** | DomPDF |
| **Email** | Laravel Mailables (SMTP) |
